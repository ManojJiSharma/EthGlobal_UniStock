# UniStock 🦄💱  
**The Most Advanced Decentralized Exchange on Rootstock**

Welcome to **UniStock**, a next-generation decentralized exchange (DEX) built on **Rootstock (RSK)** — the Bitcoin sidechain that brings Ethereum-compatible smart contracts to Bitcoin’s security layer. UniStock allows you to **swap tokens**, **provide liquidity**, and **earn trading fees**, all with **ultra-low gas costs** and a seamless user experience.

## 🚀 Features

### 🔁 Token Swapping  
- Instant, permissionless swaps  
- Powered by AMMs (Automated Market Makers)  
- Support for RRC-20 tokens & wrapped assets  
- Slippage control & trade preview  

### 💧 Liquidity Provision  
- Provide liquidity to earn swap fees  
- Dual-token & single-sided LP options  
- Real-time APY & performance analytics  
- Impermanent loss tracking (coming soon)

### 💸 Ultra-Low Gas Fees  
- Built on Rootstock (RSK)  
- Gas fees are < $0.01 on average  
- High transaction throughput  
- Ideal for both retail and high-frequency trading

### 🔐 Secure by Bitcoin  
- Secured by >60% of Bitcoin’s hash power  
- Merge-mined for maximal security  
- EVM-compatible for seamless Ethereum dev experience
